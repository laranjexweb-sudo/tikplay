DÚVIDAS FREQUENTES

Antes de entrar
na partida.

As respostas principais para quem está começando no TikPlay.

O TikPlay funciona com OBS Studio?+

Sim. Os jogos possuem telas públicas pensadas para serem adicionadas ao OBS como fonte de navegador.

Preciso instalar algum programa?+

O controle principal é feito pelo navegador. Dependendo do fluxo da transmissão, basta copiar o link do jogo e adicioná-lo ao seu software de live.

Os presentes podem causar ações diferentes?+

Sim. Cada jogo pode ter regras próprias para presentes, como revelar letras, aplicar golpes, reforçar escudos ou disparar eventos especiais.

Posso controlar a partida manualmente?+

Sim. O painel do streamer permite acompanhar e controlar a partida mesmo quando parte das ações acontece automaticamente.

O TikPlay tem mais jogos chegando?+

Sim. A plataforma foi estruturada para receber novos formatos de jogos e ferramentas de interação.
